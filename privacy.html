安中医课表插件 · 隐私政策

发布者：TcT828 · 适用版本：1.7.3 · 更新日期：2026年10月15日

本扩展是独立开发的课表辅助工具，不是安徽中医药大学官方产品，也不代表学校。本政策说明扩展如何处理数据，不替代学校网站、浏览器、文件托管网站或日历应用自身的隐私政策。

1. 处理哪些数据

用户下载或导入 ZIP/JSON 时，扩展读取文件中的学期、校区、班级、教师姓名、课程、教学场所、周次、时间、授课内容及已有的调停课信息。教师姓名和个人课表可能包含个人信息。这些信息仅用于课表显示、版本比较和用户主动发起的本地备份。

在学校课表页，扩展读取完成课表功能所需的页面选项和课程数据。用户主动导出个人日历时，使用学校个人课表接口获取对应课程；教师、场地、授课内容等写入用户下载的日历文件。按学期、校区记忆的教室或教师选择，以及用户设置的学期首周周一日期，可保存在学校站点的浏览器 localStorage 中。

2. 存储和使用

课程数据库保存于当前浏览器配置中的本扩展 chrome.storage.local，按学期、校区及版本拆分。不使用 chrome.storage.sync 云同步，也没有开发者提供的云端账户。为导入失败保护及版本管理，每个数据范围可保留一个前版本载荷。导入较旧或同时间的数据不会覆盖已有较新数据。

为在学校页面绘制课表，扩展通过页面事件桥接提供已导入数据库的必要目录信息和按学期、校区请求的本地课程数据。因此学校课表页面的脚本环境可以读取这些信息，包括已导入的相应范围数据。该桥接仅支持读取数据和打开数据管理页，不提供写入数据库或发起全校采集的操作。扩展自身不将这些本地数据上传；学校页面自身的行为受学校网站政策约束。

3. 网络通信和第三方

本政策适用于“安中医课表插件”查看端；维护者使用的独立课程数据采集器不包含在本扩展中。本扩展不包含全校批量采集流程。打开课表数据管理页或点击“刷新学期列表”时，扩展通过 HTTPS 读取 https://timdon828.github.io/ahtcm-schedule/catalog.json，取得可下载学期、采集时间、校区、文件体积和 SHA-256 校验值，每个学期只提供采集时间最新的数据库。只有用户点击“下载并导入”后，扩展才再次读取目录核对该学期最新版，并下载对应 ZIP；核对失败不会回退下载旧版。校验通过并完成必要的替换确认后才保存数据库。下载目录和数据库只作为数据处理，不作为脚本执行。

上述目录和 ZIP 请求限于发布者的 GitHub Pages 静态站点 https://timdon828.github.io/ahtcm-schedule/，不携带 Cookie 或来源页面地址，不附带学校账号、个人课表或本地课程数据，不上传数据库，也不调用 GitHub 仓库 API；请求发生重定向时会拒绝下载。网络服务仍可能处理请求地址、IP、访问时间等常规服务日志；这由 GitHub 的政策管理。本扩展没有广告、分析统计、追踪 SDK 或跨站浏览历史功能，不出售数据，不将数据用于广告、画像或信贷判断。

个人课表查询、单周日期校正和用户主动发起的日历导出，通过 HTTPS 向学校教务系统 https://jwxt.ahtcm.edu.cn/ 发送必要的学期、周次及适用的筛选参数，沿用浏览器已有的登录会话；学校服务器按自身政策处理请求和日志。本扩展不读取、保存或上传用户密码，不通过 cookies API 读取登录凭据。教室和教师的课程内容来自本地数据库，但原网页模板、页面库和部分界面图片由学校网站提供，仍需正常访问学校网站。

浏览器商店的安装、更新及浏览器自身服务不由本扩展控制。用户访问隐私政策网页、从其他来源下载课程文件或将 ICS 导入日历应用时，相应网站/应用可能处理访问或文件数据，请查看它们自己的政策。

权限用途：storage 用于保存和读取本地课程数据库；unlimitedStorage 用于容纳多学期、多校区的课程数据，不表示读取任意本地文件。学校站点权限用于在指定课表页面运行扩展和访问上述学校接口；GitHub Pages 主机权限声明为 https://timdon828.github.io/*，当前下载实现将目录和 ZIP 请求限制在上述 /ahtcm-schedule/ 路径。本扩展没有申请 cookies、history、downloads 或任意网站访问权限。

4. 用户管理和删除

用户自行决定是否下载、导入、备份或导出文件。卸载扩展会删除当前浏览器配置中的本扩展本地存储；如需清空数据库，可先导出必要备份，再卸载重装。学校站点中保存的显示偏好可通过浏览器删除该站点的本地数据，该操作可能同时退出登录。已经下载的 JSON、ZIP、Excel、ICS 文件不会因卸载自动删除；已导入手机或其他日历的事件也需要在相应应用中自行删除。

发布者无法代用户访问、导出或删除其浏览器中的本地数据库。请不要向发布者提供学校密码或登录 Cookie。自行分享数据库、课表文件或截图前，应确认有权分享并检查其中的教师、班级及个人信息。

5. 安全和限制

只使用可信发布者的文件。扩展校验下载体积、SHA-256、ZIP 结构、课程格式及学期校区范围；这些检查用于发现损坏、错包和目录不一致，并非独立的发布者身份认证。本地存储不由本扩展进行额外加密；请保护设备和浏览器配置。扩展不绕过学校登录、访问控制或数据使用限制。课程数据库是采集时点的快照，不是实时教室占用，变更以学校通知为准。

6. 发布者和政策更新

发布者为 TcT828。可通过扩展商店提供的开发者支持渠道反馈；扩展没有内置反馈上传功能。请勿发送密码、Cookie 或未脱敏的个人资料。

若未来改变下载来源、增加上传或其他数据处理方式，发布者应先更新本政策及商店披露，并在需要时征求用户同意。用户可在扩展商店核对当前版本和最新政策。
